# Документація для quote.ts

## Роль

Технічний письменник-розробник, що документує TypeScript-код для нових
учасників команди.

## Мета

Перевірити й доповнити doc-коментарі (`/** ... */`) у `app/src/quote.ts` так,
щоб вони точно описували поведінку, і додати короткий `app/README.md` з
прикладом використання.

## Контекст

- Файл: `app/src/quote.ts` — три експортовані функції:
  `estimateTotalCents`, `splitInstallments`, `formatMoney`.
- Тести (джерело правди про поведінку): `app/src/quote.test.ts`.
- Домен: суми — цілі центи; знижка — відсоток 0..100.
- Якщо існує `app/README.md` — онови його, не створюй дублікат.

## Обмеження

- НЕ змінюй код функцій, лише коментарі та README.
- Не вигадуй поведінку, якої немає в коді чи тестах — якщо не впевнений,
  познач це питанням у відповіді, а не в коді.
- Документація — українською або англійською, консистентно з рештою файлу.

- [ ] Кожна експортована функція має doc-коментар: що робить, одиниці

      округлення, розподіл залишку в `splitInstallments`).

      виклику всіх трьох функцій, команду запуску тестів.
- [ ] `cd app && npm test` лишається зеленим (документація не ламає код).
- [ ] Жодного факту в документації, який суперечить реальній поведінці
      функції (перевірено читанням коду/тестів).
